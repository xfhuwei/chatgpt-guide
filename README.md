# ChatGPT 应用与实践指南（从入门到精通）

持续更新的中文 ChatGPT 实践知识库，系统整理从使用前准备、注册登录、订阅续费，到网页与客户端操作、功能详解、场景实战和常见问题的完整学习路线。

由小小AI科技维护，属于独立第三方资料，与 OpenAI 无隶属关系。

> 知识库建设中。当前提供学习地图与建设计划，教程将逐篇补充。目录中的功能需核对适用产品、账号与版本，不代表所有账号均可使用。

## 这个知识库适合谁

- 刚接触 ChatGPT，希望从准备、注册到日常使用逐步学习的新手。
- 已经开始使用，希望查清具体功能、改善提问与回答质量的用户。
- 希望将 ChatGPT 用于工作、学习和内容创作的实践者。
- 需要核对订阅、续费、客户端差异或解决使用问题的用户。

## 每篇教程提供什么

- 适用人群与前提。
- 一个明确问题和一个具体成果。
- 可复制的练习输入或操作步骤。
- 验收清单、常见问题及改进方法。
- 资料来源、核对日期与验证状态。

功能教程尽量回答：它是什么、能做什么、在哪里进入、具体怎么操作、有哪些条件、失败如何排查。按需要补充截图、系统差异和完整案例。

优先提供原创练习和可复用资料。官方产品规则用官方资料核对；演示、个人经验和产品事实分别标明。
