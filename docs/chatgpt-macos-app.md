## 一、先查看自己的Mac配置

打开苹果菜单中的“关于本机”，记录macOS版本，以及显示的是Apple芯片还是Intel处理器。

核对日的[官方macOS下载说明](https://help.openai.com/en/articles/9275200-downloading-the-chatgpt-macos-app)列出：需要macOS 14或更高版本，支持Apple Silicon（M1或更高）或Intel处理器。官方同时说明，新桌面应用整合Chat、Work与Codex，旧macOS应用更名为ChatGPT Classic并继续支持。

这意味着查教程时要同时看日期与应用名称。若你的系统不满足当前安装要求，可以先使用网页版，不需要为此安装来源不明的修改版。

<a id="section-02"></a>

## 二、下载、安装和登录

1. 使用这台Mac打开[ChatGPT官方下载页](https://chatgpt.com/download/)，选择macOS应用。
2. 核对下载的版本与设备匹配，再按下载包里的安装提示完成安装；如出现拖入“应用程序”的提示，按该流程操作。
3. 从“应用程序”打开ChatGPT，完成系统首次打开确认及登录。
4. 使用原来网页版相同的登录方式，核对当前账号和工作区。
5. 先发送一句简单问题，确认对话正常，再测试文件和其他功能。

如果同时保留新应用与Classic，先确认自己打开的是哪一个。教程中的按钮名称和快捷入口应对应具体应用，不能把两个版本的截图混在一个步骤里。

## 三、用一份材料完成首次练习

下面的材料可以粘贴到聊天中，也可以用文本编辑工具保存为纯文本后上传。练习优先使用虚构材料，便于检查，不必一开始上传自己的工作资料。

```text
场景：准备一场30分钟的新员工工具入门分享。
听众：5位没有用过ChatGPT的同事。
要讲：官方入口、如何提问、如何核查回答。
已有材料：1张主界面截图、1个工作群通知示例。
尚未决定：具体日期、会议链接、讲师姓名。

请整理一个可执行的分享提纲。
每个环节写“目标、用时、展示材料”，合计30分钟。
把缺少的信息列在最后，不得替我编造。
```

收到结果后，先把各环节分钟数相加，再检查缺少的信息是否仍然标为未定。如果模型把讲师或日期直接补出来，要求删除，并说明原材料未提供。

<a id="section-04"></a>

## 四、快捷入口和权限怎样处理

官方macOS说明列出了 `⌥ + 空格` 快捷唤起方式。若没有反应，先确认应用正在运行，再检查应用设置与系统中是否有快捷键冲突；不要把快捷键失效当作账号不能使用。

只有在需要语音或屏幕相关功能时，再根据任务理解相应权限。单纯输入文字和上传选定文件，不需要为了“功能完整”预先允许所有权限。

<a id="section-05"></a>

## 五、安装后最常见的三个疑问

**Mac和Windows要各买一份会员吗？** 官方说明，同一ChatGPT账号可以跨设备使用原订阅，无需每台设备另买一份。[订阅与跨设备使用说明](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription) 具体权益显示有问题时，按[账号与订阅排查](chatgpt-payment-troubleshooting.md)处理。

**为什么我没有教程里的按钮？** 核对新应用/Classic、版本、当前模式及账号条件，再对照截图。不要因为按钮位置不同就认定自己装错了。

**上传失败怎么办？** 先用短纯文本测试，确认基本流程，再处理PDF或其他复杂文件。后续可阅读PDF阅读与资料提取。
