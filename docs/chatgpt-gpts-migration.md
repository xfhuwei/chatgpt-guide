## 一、先确认自己属于哪种情况

自定义 GPT 可以理解为预先配置了任务说明、参考资料和工具的专用助手。你以前创建的“公众号编辑助手”，和你收藏的别人制作的助手，处理方式不同。

| 你的情况 | 先做什么 |
|---|---|
| 自己创建并维护 | 整理配置、参考文件和日常任务，查看迁移入口 |
| 只是使用别人的 GPT | 查看作者公告，询问替代入口 |
| 从未创建过，只想固定写作规则 | 先用项目、自定义指令或可用插件完成任务 |
| 企业工作区里的 GPT | 查看工作区通知，向管理员确认安排 |

不要把能打开一个 GPT，当成自己有迁移权限；也不要把别人分享的页面当作自己的资料备份。

<a id="section-02"></a>

## 二、注意官方时间安排

官方当前计划于 **2026年12月11日** 停用自定义 GPT；**2027年2月11日**仅适用于 FedRAMP 及获批延期的特定 Enterprise 工作区。以所属账号通知为准。

出现入口后，可在 **My GPTs → Migrate to plugin** 开始迁移。迁移采用最新已发布版本，未发布草稿不会带入；“发布版本”不等于公开分享。迁移后原 GPT 在停用前仍可使用，但变为只读。新插件起初为私有，不会自动安装或向原用户开放。原模型选择与 custom actions 不会自动迁移；旧对话在停用后仍可访问。[迁移安排与范围](https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq)

## 三、先整理一份可核对的任务清单

下面是原创虚构示例，不代表某个真实账号的配置：

```text
助手名称：中文教程编辑助手
用途：把已经核实的资料改写成面向初学者的教程
固定规则：先回答问题，再给步骤；不编造实测；未知条件明确标出
参考文件：品牌术语表、文章格式示例、已批准的服务说明
外部功能：原来能查询订单状态；这一项需要单独确认替代连接
读者：只有本人，不对外分享
```

把真实配置填进去，并在本地保留你有权保存的原始参考资料。订单查询和文章写作是两项能力；后者正常，不代表前者已经恢复。

整理时删除过期活动、失效价格和早已不用的格式要求。迁移是检查旧规则的机会，不必把多年积累的冲突指令全部照搬。

<a id="section-04"></a>

## 四、用同一组任务检查替代版本

可以准备下面三项原创练习：

| 测试输入 | 应检查的结果 |
|---|---|
| 给三条已核实功能说明，要求写入门教程 | 不增加第四条未经提供的功能；顺序清楚 |
| 给一段缺少价格的服务材料，要求补全介绍 | 明确价格未知，不自己编金额 |
| 要求查询一个测试订单 | 有可用连接才查询；没权限时明确说明，不能虚构状态 |

每项都记录“原版本表现、替代版本表现、需要修正的地方”。这里列的是验收标准，不是已经测试成功的记录。

正式分享之前，还要让一个有权使用的测试账号打开替代入口。自己能用，只能证明自己的权限有效。

<a id="section-05"></a>

## 五、没有迁移按钮时怎么办

先确认是否进入创建它的账号或工作区，再查看账号通知和插件可用性。暂时没有入口时，可以先完成配置整理和任务清单；涉及业务的关键流程，也应准备能由自己手动完成的替代步骤。

如果只是想保持写作口吻和项目资料一致，可先阅读[项目、记忆与自定义指令](chatgpt-projects-memory-instructions.md)。需要使用新的可复用能力，再看[插件与连接应用教程](chatgpt-plugins-connected-apps.md)。
