# ChatGPT 回答变差怎么办？排查漏要求、长对话混乱与事实错误

资料核对：2026-11-03。适用环境：文字任务与多轮对话；示例为原创虚构材料。

> **先看结论：** 感觉 ChatGPT“降智”时，先把问题变成可以观察的错误：漏了一项要求、用了旧版本、算错了数字，还是没有读取资料。只凭一次回答变短，无法判断账号、网络或模型发生了什么变化，更不能直接断定需要购买更贵套餐。

## 一、先区分错误属于哪一类

| 现象 | 优先检查 |
|---|---|
| 答案很顺，但事实不对 | 原始材料、来源和计算过程 |
| 没按格式输出 | 格式要求是否明确，是否互相冲突 |
| 一直沿用旧日期或旧方案 | 最新版本是否明确，旧要求是否已撤回 |
| 声称看过文件，却说不出内容 | 附件是否上传完成，文件是否可读取 |
| 功能突然不能用或直接报错 | 当前模式、功能权限、限制及服务状态 |

如果是报错或文件问题，先用[功能与文件排查教程](chatgpt-feature-file-troubleshooting.md)。如果能正常回答，只是结果不符合要求，再继续本篇的方法。

## 二、用一份小材料复现错误

以下是原创练习：

```text
旧方案：培训在11月10日19:00开始，8人参加，时长40分钟。
最新确认：日期改为11月12日，开始时间改为19:30；人数和时长不变。
地点尚未确认。

请只按最新确认写一段通知。
要求：保留日期、开始时间、人数、时长；地点写“待确认”。
不要出现已经作废的日期和时间，不增加报名链接。
```

验收标准很清楚：11月12日、19:30、8人、40分钟、地点待确认，且没有旧时间和新编链接。这不是已经运行的测试结果；你可以把实际输出逐项勾选。

![旧版与新版说法冲突时，保留哪条。图中分别核对11月10日 19:00 → 有新确认、8人，时长40分钟、地点尚未确认。](../assets/teaching-figures/lesson-40-figure.png)

*每个输出字段都要能指回一条有效记录。*

<a id="section-03"></a>

## 三、要求具体修正，避免只说“重新写”

如果它用了旧时间，可以这样继续：

```text
上一版误用了旧开始时间19:00。
请改为最新确认的19:30，其余已正确字段保留。
输出通知后，再列出日期、时间、人数、时长、地点五项，便于我检查。
```

这比反复说“认真一点”“你又错了”更容易定位。官方提示指南建议提供目标、相关背景、输出要求和必要边界；本篇的逐项检查表是基于具体练习设计的编辑方法。[官方提示指南](https://learn.chatgpt.com/docs/prompting)

核对表仍可能出现错误，必须回看原始材料。尤其是金额、日期和引用，不应因为模型声明“检查通过”就直接采用。

<a id="section-04"></a>

## 四、长对话混乱时整理一张交接卡

一个对话讨论了多套方案后，可以把当前有效信息整理到新对话。不要只复制模型对历史的总结，先由自己检查关键字段。

```text
任务：写资料整理培训通知
最终事实：11月12日19:30；8人；40分钟；地点待确认
已经作废：11月10日19:00
输出形式：一段中文工作群通知
必须保留：日期、时间、人数、时长、地点状态
不要新增：费用、报名链接、讲师姓名
资料来源：本条消息中经我确认的事实
```

如果依赖附件或云端文件，在新对话中重新提供可读取的资料或准确入口，不假定另一个对话的全部内容会自动带入。

<a id="section-05"></a>

## 五、什么时候再考虑模型与模式

任务已经清楚、资料完整，但仍反复遗漏复杂约束时，可以在账号允许范围内，用相同材料比较另一种模型或思考设置。记录错误数、返工次数和耗时，比只看回答长短有帮助。[模型选择方法](https://learn.chatgpt.com/docs/model-selection)

不同回答可能有波动，一次对比不能证明某个模型永远更好。也没有足够依据把所有质量问题归因于某个网络地址或所谓“账号权重”；先用能复现的小任务排查，再决定是否调整工具。

需要长期固定要求，可阅读[项目与自定义指令](chatgpt-projects-memory-instructions.md)；准备比较模型，可用[模型与思考设置教程](chatgpt-models-thinking.md)。
