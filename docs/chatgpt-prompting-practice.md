# ChatGPT 提示词怎么写？用一个完整例子学会提问和多轮修改

[知识库首页](../README.md) · [提问、模型与回答质量](../ROADMAP.md#module-06) · [已上线教程](../README.md)

资料核对：2026-11-03。适用环境：普通文字对话；示例材料与参考结果均为原创虚构。

> **先看结论：** 好用的提示词，通常是把任务交代清楚：要做什么、根据什么、交付成什么样，以及哪些地方不能改。没有必要每次堆一大段角色设定，更不必把某个模板当成万能公式。

OpenAI的[官方提示指南](https://learn.chatgpt.com/docs/prompting)建议按任务需要提供目标、背景、输出要求与必要边界，并通过后续消息改进结果。下面用一条活动招募文案走完整个过程。

## 一、先准备事实，而不是先寻找神奇句式

假设要为一场虚构的工具分享会写招募文案，已确认的信息如下：

```text
活动名称：把工作记录变成清楚的周报
对象：刚开始使用AI的职场人
形式：线上直播分享
时间：11月12日19:30—20:30
内容：整理原始记录、生成周报、核对事实
费用：免费
报名方式：回复“周报”领取报名表
未提供：主讲人身份、参加人数、效果统计
```

这里的日期只用于练习，发布真实活动时应填写包含年份和时区的实际日期。资料没有提供的身份和效果，不能为了让文案显得可信就补出来。

<a id="section-02"></a>

## 二、写出第一版提示词

```text
请根据下方活动资料，写一段适合公众号文末的招募文案。
目标：让AI初学者了解活动内容，知道如何报名。
长度：150—220字，语气像实际组织者在说明活动。
结构：适合谁、会做什么、时间和报名方式。
约束：不虚构讲师履历、学员数量、节省时间或效果保证。
如果有必需信息缺失，先单独列出，不能自行编造。

活动资料：
（粘贴上面完整材料）
```

这条提示有用，是因为它给了明确事实与用途。第一句“你是世界顶级专家”无法替代缺失的活动时间，也无法保证文案准确。

<a id="section-03"></a>

## 三、第二轮只改一个主要问题

假如第一版写得太像广告，直接指出需要改变的地方：

```text
把开头“高效赋能、全面提升”等抽象表达改成具体场景：
工作做了不少，但写周报时不知道怎么整理。
其余活动事实保留。不要增加夸张效果，不要改动报名口令。
```

如果段落太长，再进行第三轮：

```text
把这版拆成3个短段落，最后单独放报名方式。
保留活动时间、免费、三个学习内容。
输出可以直接复制的正文，不要附写作解释。
```

一次明确一个主要问题，便于比较改动带来的影响。若同时提出十几条互相冲突的要求，结果不稳定时也很难定位原因。

*改表达后，回看时间、费用和报名方式三个事实。*

<a id="section-04"></a>

## 四、最后一轮做事实核对

```text
对照最初活动资料检查最终文案。
用表格列出：事实项目、原资料、最终文案、是否一致。
特别检查日期时间、费用、报名方式，以及是否新增了未经提供的效果或身份。
先报告差异，不要擅自修改正文。
```

模型可以帮助找差异，但最后仍要自己对照原始材料。尤其是数字、承诺和专有名词，不应只相信它的一句“全部一致”。

<a id="section-05"></a>

## 五、遇到这三种问题，换一种提问方式

**答案很空：** 增加一份真实材料或具体场景。例如把“帮我写周报”改成“根据下面五条记录，整理已完成、问题和下周计划”。

**总是编细节：** 明确哪些内容只允许来自材料，把建议和事实分开，让缺失信息保留为待确认。

**改了A，又把B改坏：** 指定保留内容和修改范围，例如“只改第二段的语气，日期、金额和最后的报名方式保持原样”。

可以保存下面这个短模板，下次按需要填，而不是每项都必须写满：

```text
我要完成：
给谁看或用于哪里：
依据材料：
希望的格式和长度：
必须保留的事实：
缺少信息时如何处理：
```
