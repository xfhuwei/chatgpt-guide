## 一、先确认自己是否具备入口

当前[官方Space入门说明](https://help.openai.com/en/articles/20001549-getting-started-with-space-in-chatgpt)列出Pro、Business和Enterprise可创建、编辑Space内容，并注明手机端主要用于查找、阅读和分享，暂不支持编辑页面。组织权限及地区开放也可能影响实际可用性。

没有Pages入口时，可以先用[普通文字对话](chatgpt-prompting-practice.md)或[Word文件](chatgpt-word-ppt-files.md)完成稿件，不需要照着旧版Canvas截图猜按钮位置。

<a id="section-02"></a>

## 二、创建一个只用于练习的页面

在支持的环境中发起任务：

```text
请创建一个私人Pages页面，标题为“资料整理分享说明－练习稿”。
先不要共享。正文使用下面的虚构材料：

面向8位新同事，计划安排40分钟的资料整理分享。
演示10分钟，个人练习20分钟，讨论10分钟。
参与者准备一段不含私人信息的工作记录。
活动日期和讲师尚未确定。

页面分为适合谁、环节安排、参加前准备、待确认事项四节。
```

打开生成页面，先确认四节都存在、40分钟合计正确、未知信息仍保留。这里的目标是得到可编辑页面，不是只得到一条“已创建”的文字回复。

<a id="section-03"></a>

## 三、选中一段文字进行局部修改

选中“适合谁”的段落，在出现的工具栏中使用Ask for change，提出具体要求：

```text
只把选中的段落改得适合没有AI经验的读者。
保留8位新同事这一事实，不添加能力承诺。
其他章节和时间安排不变。
```

官方[Pages编辑说明](https://learn.chatgpt.com/docs/space/pages)介绍了选中文字、请求修改和添加评论的方式。修改完成后，对照前后段落，确认目标段落改变了，而数字与其他章节没有被顺带改写。

如果改动不合适，使用当前页面提供的撤销方式，或明确要求恢复指定内容。需要保留的审定版本应另行记录，不把“模型记得原文”当作唯一恢复方案。

*对照选区内外各检查一次。*

<a id="section-04"></a>

## 四、评论和正文分别放什么

正文写读者最终要看到的信息；评论记录“这里要补截图”“这句话需确认”等审稿意见。选择具体段落再评论，比在聊天中说“中间那段不对”更容易定位。

例如，在日期待确认的位置添加评论：“正式发布前填写实际日期，暂不由AI补全。”完成确认后，更新正文并处理对应评论，避免待办和定稿长期混在一起。

页面支持内容块组织。移动段落或表格时，检查移动范围，特别留意标题下的内容是否随之移动；不要只看标题到了新位置。

<a id="section-05"></a>

## 五、共享前检查正文与权限

需要协作时，在Share里确认对方是查看还是编辑权限。页面可能从父页面或所属Space继承访问权限，取消一条直接邀请不一定消除其他访问来源。

此外，原资料中的内容一旦被复制进共享页面，能看页面的人就能读到这些文字，即使他们没有原文件权限。先删去不该共享的信息，再确认访问范围，最后分享。

一次完整练习的合格结果是：页面实际存在、局部修改符合要求、40分钟安排未变化、待确认信息仍清楚、共享范围符合你的意图。

如果目标是交付可离线编辑的文件，继续采用[Word与PPT成果流程](chatgpt-word-ppt-files.md)；页面组织和聊天项目的区别，可结合[资料库与Space](chatgpt-library-space-files.md)理解。
