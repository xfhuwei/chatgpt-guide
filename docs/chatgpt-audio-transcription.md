## 一、先确认文件和入口

当前官方文件说明支持付费订阅与相应工作区上传音频，列有MP3、WAV、M4A等格式；音频识别受语言、文件和账号环境影响。仅把视频文件改成音频扩展名不能完成转换。[音频上传说明](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)

从附件入口选取你有权处理的录音，等待上传完成。长录音可以先选一段测试，确认能读取、语言正确，再处理完整材料。

<a id="section-02"></a>

## 二、用一段自己的录音练习

可以自己朗读下面的虚构内容并保存为音频：

```text
这是一次练习。培训原计划在十一月十日进行，现在改到十一月十二日。
开始时间为晚上七点半，参加者八人，活动持续四十分钟。
小林负责准备PDF讲义，但还没有确定提交时间。
是否增加录屏，需要另行确认。以上安排没有包含报名费用。
```

上传后发送：

```text
先转写这段音频，不做摘要。
尽量保留原句中的更正、否定和未确定事项。
听不清的地方标注[听不清]，不要按上下文猜数字。
如果能提供可靠的时间位置就附上；无法定位时明确说明。
```

<a id="section-03"></a>

## 三、重点检查四类容易出错的信息

回听日期与时间，确认最终日期是11月12日、开始时间19:30。核对人数8和时长40分钟。检查“还没有确定提交时间”，不能变成已经安排截止日期。检查录屏仍待确认，不能写成已决定。

多人录音还要核对发言归属。模型提供的Speaker 1等标签不等于真实姓名已经确认；发生抢话、口音或噪声时，更不能仅凭语气猜身份。官方也提醒转写及说话人识别可能出错。[音频准确性说明](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt)

<a id="section-04"></a>

## 四、确认转写后再提取纪要

```text
请基于已经核对的转写，整理：已确定安排、行动项、待确认事项。
每个行动项写负责人和期限；材料没给期限就写“未确定”。
保留原始转写，另输出摘要，不覆盖它。
```

本练习应保留小林准备PDF、期限未确定，以及录屏待确认。不要把“没有包含报名费用”改写成“活动免费”，两者含义不同。

<a id="section-05"></a>

## 五、文件太长或读取失败怎么办

先确认音频能在本机播放，格式与账号支持范围一致。长文件拆分时保留顺序与原始时间范围，避免每段都从00:00开始后失去定位关系。分段摘要合并前，检查重复内容和跨段未完成的句子。

失败排查见[附件问题处理](chatgpt-feature-file-troubleshooting.md)。想直接录制并整理，可看[Record录音流程](chatgpt-record-meetings.md)；完整纪要表达参考[会议纪要与周报](chatgpt-meeting-weekly-report.md)。
