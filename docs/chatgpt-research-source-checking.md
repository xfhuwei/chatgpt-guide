## 一、先挑出需要证据的句子

不用把所有表达都查一遍。优先标记数字、价格、功能可用性、限制、日期、比较结果和对外承诺。像“建议先试用一个小任务”属于方法建议；“所有套餐均支持导出全部历史版本”则需要明确依据。

ChatGPT的搜索可以提供来源，研究报告也可附引用，但仍需由读者核对。官方使用指南强调检查成果与材料是否一致。[使用与结果检查](https://learn.chatgpt.com/docs/use-chatgpt)

<a id="section-02"></a>

## 二、用四列表把结论拆开

```text
请把这篇回答中可以核实的关键主张列成表格。
字段：主张、对应来源链接、来源中支持它的位置、适用日期与范围。
没有直接证据的主张标为“待核实”，不要补造引用。
同一段包含三个不同结论时，拆成三行。
```

然后自己打开来源。不要只阅读搜索结果摘要，因为摘要可能截断条件，或者仍显示页面的旧内容。

<a id="section-03"></a>

## 三、练习：这句话是否被原文支持

以下是虚构资料，不对应真实产品：

> 资料甲：“个人专业版可导出当前文档为PDF，历史版本不包含在导出文件中。”

待检查结论：“所有用户可以一键备份全部文档和历史版本。”

至少有三处不成立：适用对象从专业版扩大到所有用户；导出当前文档变成全部文档；明确不包含历史版本却被改成包含。即使引用链接真的指向资料甲，这句话仍属于错引。

更准确的改写是：“资料甲说明，个人专业版可把当前文档导出为PDF，导出不包含历史版本。”这只是练习答案，不是某个产品的事实。

![一个引用能支持整句话吗。图中分别核对所有用户、全部文档、包含历史版本。](../assets/teaching-figures/lesson-42-figure.png)

*链接能打开之后，还要核对对象、动作和范围。*

<a id="section-04"></a>

## 四、遇到来源冲突，怎样处理

先记录两份资料的发布时间、实际适用版本和对象。新版帮助页可能适用于刚开放的功能，旧公告可能只说首发安排；发布较晚也不自动证明覆盖全部账号。

可以继续问：

```text
资料A与B对功能范围的描述不一致。
请分别摘录短小的关键条件，说明适用对象和日期。
能确认的共同部分先列出；无法解释的差异保留为待确认。
不要凭发布时间直接认定另一份资料错误。
```

对暂时无法打开的网页，记录“本次无法读取”，不能直接写“网站已倒闭”或“功能已取消”。必要时寻找同一机构的其他现行说明。

<a id="section-05"></a>

## 五、发布前保存哪些信息

保存主张、直接来源、查阅日期与适用条件。短引用只保留核对所需部分，不把完整网页复制进自己的文章。网页更新后，要回到原主张检查影响范围，而不是只刷新文章日期。

没有足够证据的结论，可以缩小表述范围、明确不确定性，或者暂时删除。完整研究流程见[深度研究实践](chatgpt-deep-research-workflow.md)；涉及PDF里的依据，另看[PDF阅读与定位](chatgpt-pdf-reading.md)。
