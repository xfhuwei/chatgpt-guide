> **先看结论：** 想体验AI编程，可以先做一个离线人数计算器：输入三组人数，显示合计、剩余名额和超额提示。范围足够小，结果能手算，也不需要登录、数据库或发布网站。

## 一、把需求写成可以验收的规则

```text
请制作一个中文离线人数计算器，交付单个HTML文件。
总容量默认20人，可修改；输入三组人数。
空白组人数按0处理，只接受非负整数，非法输入明确提示。
显示合计人数；未超额显示剩余名额，超额显示超出人数。
不联网、不提交数据、不使用外部字体或脚本。
在桌面和窄屏下都能看清输入标签与结果。
```

明确是离线HTML，能避免它把简单计算任务扩成一个要注册服务器的完整系统。官方文件预览说明介绍了在支持环境中查看HTML成果；实际交付仍应检查文件。[文件与HTML预览](https://learn.chatgpt.com/docs/artifacts-viewer)

<a id="section-02"></a>

## 二、先检查界面和文件是否真实存在

若得到完整HTML代码，可以保存为 `participants.html`，确认扩展名不是 `.html.txt`。若得到附件，下载后用浏览器打开。支持预览的界面可先试用，再检查下载文件是否表现一致。

输入框需要明确标签，不能靠占位文字让人猜用途。结果旁应写“人”，不要只显示一个没有含义的数字。

## 三、用这张表检查行为

| 容量 | 三组人数 | 预期 |
|---:|---|---|
| 20 | 8、6、4 | 合计18，剩余2 |
| 20 | 10、8、5 | 合计23，超出3 |
| 20 | 空白、空白、空白 | 合计0，剩余20 |
| 20 | －1、2、3 | 提示非法输入 |
| 20 | 1.5、2、3 | 提示必须为整数 |

非法输入时，结果不能继续显示上一次成功值而没有说明，否则用户容易误以为当前数据已算完。修改后应能恢复正常计算。

## 四、提出一次具体修订

假设窄屏下按钮挤在一起，可以要求：

```text
只优化窄屏布局，让三个输入框纵向排列。
保持计算规则和结果不变。
错误提示显示在对应字段附近，并能说明如何改正。
完成后再按五组样例检查。
```

不要一次把配色、公式、数据保存、语言和导出全改掉；无法判断新问题来自哪一项时，先缩小改动范围。

## 五、离线文件与正式网站怎么衔接

这个练习不需要保存用户记录，刷新后输入是否保留应按你的要求定义。以后要让多人提交报名、保存信息或管理权限，就属于另一层需求，不能只把HTML传到网上便认定已经具备安全的多人系统。

想继续托管成网站，可看[Sites建站流程](chatgpt-sites-website-workflow.md)；程序出错时按[代码排错](chatgpt-coding-debugging.md)提供输入、现象与预期。
