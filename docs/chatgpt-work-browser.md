## 一、内置浏览器和原来的浏览器有什么不同

ChatGPT 内置浏览器使用独立的浏览环境，不会自动沿用你在 Chrome 等浏览器里的登录状态。桌面端可通过 `@Browser` 指定内置浏览器；如果需要已有浏览器中的页面和登录上下文，可以使用受支持的浏览器扩展。[内置浏览器说明](https://learn.chatgpt.com/docs/browser)

当前扩展支持 Chrome、Edge、Brave、Opera、Vivaldi，侧边聊天支持范围另有区别，具体以设备和开放情况为准。只想对比公开网页时，通常不需要先连接自己的私人邮箱或后台账号。[浏览器扩展说明](https://learn.chatgpt.com/docs/chrome-extension)

## 二、先做一个只读取资料的任务

选择两篇你能打开的公开教程，复制真实链接。下面的提示词需要先替换“链接A”和“链接B”：

```text
请打开以下两篇公开教程：
链接A：替换为第一篇真实链接
链接B：替换为第二篇真实链接

比较它们的目标读者、前置条件、操作步骤和更新时间。
输出一张对照表，每项结论注明来自哪一个页面。
找不到更新日期就写“页面未注明”。
只读取内容，不登录、不提交表单、不下载附件。
页面要求下载或登录才能继续时，告诉我缺失了哪些信息。
```

支持的界面中选择内置浏览器再发送。不要把“比较两篇教程”理解成“帮我选所有相关产品”，目标越具体，越容易检查是否完成。

<a id="section-03"></a>

## 三、别只看最后一张表

自己打开两个来源，检查至少四项：

1. 读取的是否为指定页面，而非搜索结果里标题相似的另一篇。
2. 页面写的是适用条件，还是作者的建议，输出是否区分。
3. “页面未注明”是否真的来自缺失信息，而非没有展开完整正文。
4. 来源链接能否定位到支持该结论的内容。

例如，页面A只说明网页版，页面B明确写桌面端，不应合并为“全平台通用”。发布日期也不能自动等于功能最后核实日期。

这是核对方法，不是对任意页面内容的事实判断。真实比较结论必须在打开你选定的资料后填写。

<a id="section-04"></a>

## 四、什么时候使用浏览器扩展

如果任务依赖你已经登录的受支持网站，可以按官方设置说明安装对应扩展，然后把指定标签页加入聊天。先检查被引用的标签页是否正确；浏览器里打开很多页面时，不要只说“看看这个”。

需要修改网站内容时，把指令写成可复核的动作，例如“把这段文案填入草稿，完成后停在预览页”。涉及发送、下单或发布时，核对收件人、金额、版本和最终确认页面后再继续。

网页文字可能包含不相关指令。页面是待分析材料，不能因为页面声称需要登录其他站点，就把账号资料交给它。官方同样要求把网页内容视为不可信上下文。[扩展使用与权限提醒](https://learn.chatgpt.com/docs/chrome-extension)

<a id="section-05"></a>

## 五、打不开或无法操作时怎么处理

先尝试自己打开原网页，区分网站故障、登录要求和浏览器权限问题。若内容需要专门插件读取，优先考虑可用连接；若页面只能手动操作，可以自己完成关键步骤，再让 ChatGPT 根据可提供的资料继续。

不要把浏览器可读网页理解为它可以完成任何上传或下载流程，具体动作受工具能力与权限限制。想先熟悉资料查证，可阅读[联网搜索教程](chatgpt-search-research.md)；需要连接云端文档，可看[插件与应用连接](chatgpt-plugins-connected-apps.md)。
