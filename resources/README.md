## 先选一组开始

文件工作先做双版本对比；表格工作先清洗6行数据；代码入门先检查3笔与260.00；内容工作先确认计划3张、完成2张、未发布的状态。

这些是原创虚构材料和编辑参考答案。参考代码已有指定本地样例检查；在ChatGPT里生成的内容仍需实际核对，不代表每个账号都具备相同功能。
